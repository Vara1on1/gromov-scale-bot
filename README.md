# 🚀 Gromov Scale Bot (@gromov_scale_bot)

Флагманский Telegram-бот, объединяющий:
1. **🛠️ Инженерный AI-Генератор ТЗ для Cursor & Claude:** утилита, превращающая сырую идею в чистое ТЗ со стеком, структурой и блоком ограничений (`Negative Constraints`), чтобы код компилировался с 1-й попытки.
2. **💎 Закрытый Клуб & База Знаний (MRR Paywall):** регулярная подписка на библиотеку проверенных System Prompts, готовые бойлерплейты проектов и закрытый чат инди-разработчиков.
3. **👥 Реферальная система:** виральный приток новых пользователей (по +3 генерации за приглашенного друга).
4. **👑 Админ-панель:** детальная статистика, ручная выдача подписок и рассылка по всем пользователям.

```text
│   ├── profile.py        # Личный кабинет и рефералка
│   └── admin.py          # Админка, рассылка и статистика

```

## ⚡ Быстрый старт на бесплатном хостинге (Render.com / 24/7)

Чтобы бот работал круглосуточно без включенного компьютера и без затрат (0 ₽):

1. Создайте бесплатный аккаунт на [Render.com](https://render.com) или [Railway.app](https://railway.app).
2. Загрузите папку с ботом в свой приватный репозиторий на GitHub.
3. На Render.com нажмите **New +** → **Background Worker**.
4. Подключите ваш GitHub репозиторий.
5. Заполните настройки:
   * **Runtime:** `Python 3`
   * **Build Command:** `pip install -r requirements.txt`
   * **Start Command:** `python main.py`
6. В разделе **Environment Variables** добавьте:
   * `BOT_TOKEN` = `8814312826:AAFIMWSQ-fXhLh0fthzW3chPoV1XL-kfhD4`
   * `ADMIN_ID` = ваш Telegram ID (узнать можно в `@userinfobot`)
7. Нажмите **Deploy**. Бот запустится в облаке за 1 минуту!

## 💳 Как подключить оплату подписки через Tribute за 0 ₽

1. Откройте в Telegram официального бота [@tribute](https://t.me/tribute).
2. Зарегистрируйтесь (принимает самозанятых и физлиц, абонентской платы нет).
3. Создайте продукт типа **Подписка**:
   * Тариф 1: `1 месяц` — `790 ₽`
   * Тариф 2: `3 месяца` — `1 990 ₽`
4. Скопируйте полученные ссылки на оплату и вставьте их в файл `.env`:
   ```env
   PAYMENT_URL_MONTH=https://t.me/tribute/app?startapp=...
   PAYMENT_URL_QUARTER=https://t.me/tribute/app?startapp=...
   ```
5. Деньги автоматически выводятся на любую российскую карту.
